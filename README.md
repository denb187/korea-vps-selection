## 三网回程与延迟：韩国节点最容易含糊的一环

韩国离中国近，延迟低是地理决定的，但线路走法决定晚高峰稳不稳。Evoxt 首尔走 KT 普通直连，公开测评给出的三网回程如下：

| --- | --- | --- | --- |
| 电信 | KT → AS163 中国电信骨干 | 约 40–50ms | 直连，晚高峰有丢包 |
| 联通 | KT → AS4837 联通 169 | 约 45–50ms | 直连，日常稳定 |

## 谁适合，谁不适合

**联通用户**可以直接上。AS4837 直连首尔，45–50ms，晚高峰基本维持可用，建站、远程桌面、跑脚本都顺。

**电信用户**先测再买。白天用没问题，晚高峰丢包是实打实的短板。测完能接受就买，不能接受就去看狗云弹性云（电信去程 CN2）或朝暮数据 CN2 区（5Mbps 带宽换不限流量）。

**外贸建站、个人博客**：高主频跑 WordPress 后台比低频机器顺手，VM-1 或 VM-2 够用。

**跨境电商、韩区业务落地**：韩国原生 IP 加 KT 线路，适合韩区账号注册、API 对接、本地内容分发。

**TikTok 运营**：TikTok 解锁到美区，1Gbps 上传不卡，VM-2 起步更稳。

**需要 Disney+ 韩国区、需要三网 CN2 GIA/9929**：这两类需求这台机器满足不了，不用勉强。

## 下单前常问的几个问题

**$2.99 的 VM-0.5 到底能跑什么？**

**能不能装 Windows？**
可以，但需要 VM-1 及以上。Windows Server 2012/2016/2022 都在模板列表里，512MB 和 1GB 那两档只能 Linux。

**电信到底能不能用？**
能用。40–50ms 的延迟本身不差，问题在晚高峰丢包。建议下单前先拿测试 IP 跑一轮自己常用时段的 ping 和丢包率，能接受再买。
